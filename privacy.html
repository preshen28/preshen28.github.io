Privacy Policy

Last updated: 23 November 2026

What this app is

"yt-channel" is a private tool used only by the owner of the YouTube channel Secretly Simple (@SecretlySimple28) to manage that one channel. It is not offered to the public, and no other users sign in to it.

What data it accesses

  • Analytics for the owner's own channel and videos (for example views, watch time and subscriber counts), through the YouTube Data API and YouTube Analytics API.
  • Public comments on the owner's own videos, so the owner can read and reply to them.

How the data is used and stored

The data is used only to understand how the channel's videos perform and to reply to viewers. It is stored on the owner's own computer. It is not sold, shared with third parties, or used for advertising. Sign-in tokens stay on the owner's computer and can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
